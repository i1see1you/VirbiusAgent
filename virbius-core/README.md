# virbius-core

Edge (in-process) security SDK for AI Agents: tool-call precheck, License
verification, DLP masking, STI taint tracking, and Prompt Gateway.

Part of [VirbiusAgent](https://github.com/i1see1you/VirbiusAgent) — an open-source
four-tier **Edge–Gateway–Kernel–Cloud** security platform for AI Agents.

## Install

```toml
[dependencies]
virbius-core = "1.0"
```
