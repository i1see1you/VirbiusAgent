# 对局页（短期）

学 Lakera 的结构，不抄图和商标。文案中文。改 Vue 后 `web/` 里 `npm run build`，再硬刷新。

## 布局分流

有可投毒的**工件**（工具描述 / 网页 / PDF / 规则 / 文书 / 记忆日志）→ 三栏：信息 | 攻击面 | 预览。

**直输关没有中栏。** 攻击就是跟应用说话，中间再开一块「添加攻击」没有用途，省略。两栏：信息 | 对话（输入就在聊天里）。

## 共用：左栏 HUD

1. 顶栏：左 **返回** → `/`（历史打开时改成 **关闭历史**，不跳走）；右簇 **时钟 + 次数** 再 **九宫格**。九宫格展开 10 关（当前高亮，`n/3 档`）。`@click.stop` 只加在九宫格和面板上。
2. 历史按钮：高 36px、描边 `#26292c`，与九宫格同高；数字是本档全部尝试（含失败），0 次禁用。`aria-pressed` 表示开着。Esc 关闭。
3. 历史打开时左栏正文换成记录列表，不叠在目标说明上面。每页 5 条、新的在前。卡片：截断攻击文案、相对时间、第 N 档、分数徽章、**查看回复**。点卡片：手机换成那一轮；**工件关**把攻击文案填回中栏槽并切到攻击页签（旅行规划的网页、PDF、日志、文书、MCP 描述都一样）；直输关只回填对话。分数环跟该次分数。不把旧气泡堆在对话框里。
4. 当前目标 → 应用名 → tagline → **第 1/2/3 档** 药丸（`nowrap`，约 14px）→ 分数环 → 场景 / 攻击目标 / 攻击方式（图标 + 15px，不要全大写）。
5. 不展示 `disclaimer`。
6. 三栏/两栏舞台下 HUD 无蓝卡片：无背景、无阴影，右边框 `1px #26292c`。

## 三栏（工件关）

- 比例：左栏 `max 28rem`（Lakera `max-w-md`），中 `1.5fr`，右 `1fr`。左栏不再跟另外两栏按 1:1.5:1 一起涨。
- 中栏：「添加攻击」/ 「这是用来攻击该应用的工具。」 / 「发起攻击」。工件顶条 `#027d82` / 内 `#cceef0`，代码底 `#19354a`。槽不要纯白，placeholder「在此插入攻击…」，`0 / 10,000`。
- 右栏只出不进：微信预览，黑边 10px，宽高比 466/968。底栏装饰不能打字。
- 窄屏 &lt;1280：页签 **信息 / 攻击 / 预览**，默认攻击。

## 两栏（直输关）

- 比例：左栏同样 `max 28rem`，右栏 `1fr` 吃掉原来中+右的空间。不要 1:1.5 把信息栏拉宽。
- 右栏同一部手机，底栏换成真输入：「发送消息」+ 绿色 **发送**。攻击从这里发，绿泡自己、白泡对方。
- 窄屏页签 **信息 / 对话**，默认对话。没有「攻击」页签。
