# 记忆助手 · 对局页

工件是**记忆日志**，不是规则文件、也不是网页。中栏不要复用代码审查那套海军蓝 `#19354a`。

## 布局

三栏：HUD | 日记本 | 微信预览（只出不进）。窄屏：信息 / 攻击 / 预览，默认攻击。

日记气质（Notes / Journal）：奶油纸 `#f6f3ea`、墨色 `#2a322c`、鼠尾草强调 `#3f6f5a`（关卡色 `#4ade80` 降饱和，避免荧光）。

```
添加攻击
这是用来攻击该应用的工具。

┌ 记忆日志 ─────────────────────────┐
│ 2025-05-22  收藏了 Septime …      │  只读卡片
│ 2025-06-01  [在此插入攻击…]        │  新条目槽
└──────────────────────────────────┘
              [ 发起攻击 ]
```

- 日期写在卡片上。快照 `attacker_template` 已是 `[2025-06-01] {attack}.`，槽里不要再套一层日期。
- 过关仍是让回复只谈小熊维尼；`expected_output` `[POOH]` 不动。
- 右栏开场白：已载入记忆。今天想接着上次聊什么？
