## FAQ

**Q: What is VirbiusAgent?**
A: A multi-layer AI agent security protection system. See [README.md](README.md) for details.

**Q: How do I start the services locally?**
A: Run `scripts/run-local.sh` to start all services with default configuration.

**Q: How do I configure the MCP Proxy?**
A: See [PROXY_CONFIG.md](PROXY_CONFIG.md) for the complete configuration reference.

**Q: Where can I report a security issue?**
A: Use the [GitHub Security Advisory](https://github.com/i1see1you/VirbiusAgent/security/advisories) page. See [SECURITY.md](SECURITY.md) for details.
