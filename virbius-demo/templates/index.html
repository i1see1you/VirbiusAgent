Agent 靶场（dvla）

脆弱的 ReAct 银行客服：越权读取他人交易 + UNION 注入窃取密码。基于 langchain 真实 ReAct agent。

玩法说明

① 每个 lab 都有明确的攻击目标（flag），攻破后会自动记录通关状态（存于会话）。

② 所有“被攻击”的大模型都可切换（DeepSeek / OpenRouter / 本地 Ollama），真实可被提示注入绕过。

③ 顶部 VirbiusAgent 防护 开关：开启后攻击请求会先经过防护引擎评估；关闭则直连脆弱模型、暴露漏洞。用于直观对比"有防护 vs 无防护"。

④ 这是防御教育用途：理解攻击面 → 学会缓解。请勿对未授权目标使用。
